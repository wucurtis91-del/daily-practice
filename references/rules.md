# 每日规则（通用默认）

这是 skill 自带的默认规则。用户自己的规则文件（config 的 `rules`，默认 `<资料夹>/rules.md`）优先，没写到的照这里。计划、出题、审核、拼卷、最终检查的 agent 读的是用户的规则文件，所以建档时要把这里的要点抄过去，用户自己的规定也写在那里才会生效（模板在最后）。

下面的例子都是虚构的两门课：ENGR1001 Circuits 和 MATH1001 Calculus。

## 1. 题量

- 默认一天约 2 小时（`daily_minutes` = 120），绝不超过。
- 每门课的时间 = `questions_per_day` 道 × `marks_per_question` 分 × `minutes_per_mark` 分钟。`minutes_per_mark` 是真卷的总时长除以总分：3 小时、100 分的卷子就是 1.8。
- 实际出多少题由这几个数决定，`daily_minutes` 是上限。各门课加起来要接近 `daily_minutes`：差 15% 以上 `check_config.py` 提醒，差 20% 以上报 ✗；工作流遇到差 20% 以上的，按两者里小的那个说时间，题数超了就在计划时删题。
- 某门课暂时不出题：`questions_per_day` 写 0（交回来的卷子照样批改）。
- 怎么分：每门要考试的课每天都有题，至少一道是整道真卷大小的题。考试近、分量重的课多给一些。例：ENGR1001 两道 20 分（2 × 20 × 1.8 = 72 分钟），MATH1001 两道 10 分（2 × 10 × 2 = 40 分钟），合计约 2 小时。
- 原题保留它自己的分值，范围是 `original_marks`（默认每题分值的 75% 到 100%）。
- 建议用时按分值算出来，印在封面上。

## 2. 轻松日

- 题量减半：每门课 `light_questions` 道（默认 1 道），一天约 1 小时。
- 下面任何一条成立就是轻松日：
  - 计分作业截止、实验、测验、考试的前一天和当天（从学习平台助手读；没有助手就看规则文件里的日历）；
  - 学生在学习平台助手里记录的状态是累、来不及、病了；
  - 学生今天的要求里说累、不舒服、没时间；
  - 规则文件「临时安排」里这一天写着轻松日。
- 「临时安排」里这一天写着停：只批改，不出卷（`mode` = `grade-only`）。

## 3. 每天怎么选题

1. 到期的复练排在最前面（见第 7 节）。
2. 每门课通常一道考最近一周教的内容，一道考以前的。
3. 一周之内轮换考试的题型（按 `source-map.md` 里的题型），不要连着几天考同一种。
4. 同一道原题 7 天内不重复用作变题的基础，复练除外。
5. 学生今天的要求在规则允许的范围里照办：只考教过的，不超时，复练优先。办不到的在计划的 notes 里说明。

## 4. 变题（默认）

- 每道题都以一道原题为基础：往年卷、模拟卷、习题、课件例题。
- 考点和题型不变，问法和真卷一样。至少改下面一样，最好两样：
  - **数据**：换数值，挑能算出干净结果的；
  - **结构**：电路多一个元件、换一种接法，矩阵换阶数或者换特殊结构，积分换被积函数的形式；
  - **问法**：倒过来问（已知结果求参数）、加一个设计要求，或者把两个已经教过的知识点放进同一道题。
- 难度同款或更难，不能更容易。审核那一步会拿原题比较，说清难在哪里。
- 不能照抄，也不能只换个数字或者只改题号。
- 每个答案都要数值核对：电路题用 `mna.py` 精确求解，其他用 Python / numpy。

## 5. 原题（偶尔）

- 每周约两道（`originals_per_week`），一天最多一道。原题做错后一周原样再考的那一次（见第 7 节）不算在里面。
- 原样照搬：措辞、数据、小问结构和分值都不改，只改题号和图号。原题引用了没收进来的别的题，就做最小的改动，并在 meta.json 里写明。
- 封面写明：「Question n is reproduced from …」。
- 优先选有官方答案的原题；没有官方答案的，自己解一遍并数值核对，作为答案。

## 6. 只考教过的

- 已学范围：学习平台上已经上过的课（周模块、讲义页面、上课日期已经过了的）。没有学习平台助手，就看规则文件和每门课的 `taught_notes`；那里没写的不算教过。
- 课件里有、原题地图里标「以后」的内容，等那节课上过才能用。
- 新课件先下载到课程的 materials 文件夹，用 `extract.py` 提取文字，再拿来出题。
- 诊断测验、入学测试之类的结果，不拿来定弱项，除非用户自己要求。弱项只看每日练习实际批改出来的结果。

## 7. 错题和复练

- 批改时，错的、漏的一律标「重点」（批改 PDF 里是红字），写清错在哪一步、回去看讲义的哪一节或者课件的哪一页。
- 每处错误在课程文件夹的 `practice/error-log.md` 里记一行 ⭐：
  `- ⭐ <日期> Q<n>(<小问>) <主题>：<错在哪>。Retest: <日期 + 2 天>, <日期 + 7 天>`。原题做错的在后面加「(original: retest as-is on <日期 + 7 天>)」。
- 到了 Retest 里的日期就复练；`retest_days` 默认 `[2, 7]`。
  - 变题做错的：每次复练都出一道新变题，专门考上次错的那一步。
  - 原题做错的：前面几次（默认 2 天那次）同样出新变题；最后一次（默认 7 天那次）原样再考这道原题，`kind` 是 original、带 `retest_of`，不占 `originals_per_week` 的名额。
- 某个日期的复练算出过了：`log/questions.jsonl` 里有一道 `retest_of` 指向它、日期是那天（或者更晚）的题。复练又做错，批改时会再记一行新的 ⭐，从新的日期重新算。
- 错题本和题目记录只追加、不改写：几个 agent 可能同时在写，一律用 `tools/log_append.py`（加锁追加）。

## 8. 卷面

- 排版照这门课的真卷：字体、边距、页眉页脚、题号和分值的写法、图注、封面。
- 每道题另起一页。每个有分值的小问后面留空白作答（`\AnswerSpace`），不画答题框。
- 卷子里没有答案、提示或出题说明。答案单独放在 `practice/.answer-keys/` 里。
- 封面：建议用时、课程名称、日期、练习场次、说明，再加每道题的出处一行：
  - 变题：「Question 1 is adapted from …」
  - 原题：「Question 2 is reproduced from …」
  - 复练：后面加「 (retest)」
- 封面写自学练习卷，不冒充官方试卷，不印学校名、校徽和版权行，不抄考场须知里只对正式考试成立的话。

## 9. 不要碰的

- 还开着的计分作业、在线测验、实验报告里的题，不拿来当原题，也不出几乎一样的变题。
- 每周的辅导课习题，答案公布之前不用。
- 这些写进 `source-map.md` 的「不要碰」一节。

## 10. 每道题的检查

- 出题人自己核对数值，再用 stub 单独编译这道题并看渲染出来的每一页。
- 另一个 agent 只看渲染出来的页面图盲解一遍，不看源文件和答案。
- 审核人比较两份答案，查图、范围、难度、措辞、分值、答题空白和评分要点；有必须改的就返工，最多 3 轮。3 轮还没通过的题拿掉，交付时照实说。
- 拼好卷子之后，再由一个 agent 独立检查整份卷子，有问题的按课程改好再交。

## 11. 努力程度

每个 agent 都用 config 的 `effort`，默认超高（xhigh）。工作流给每次调用都写死了，不跟会话的设置走。

## 12. 文件放哪

| 什么 | 放哪 |
|---|---|
| 每道题的工作文件 | `<资料夹>/staging/<日期>/<题号>/`（question.tex、solution.md、meta.json、verify.txt、circuit.json、png/、blind-r*/） |
| 每门课的卷子 | `<课程文件夹>/practice/daily/<日期>/<CODE>_Daily_<日期>.pdf`（还有 .tex、.sty、q*.tex、png/） |
| 合成的一份 | `delivery.dir/<日期> 每日练习.pdf`（文件名见 `delivery.combined_name`，课程顺序同 config） |
| 答案 | `<课程文件夹>/practice/.answer-keys/daily/<日期>.md` |
| 题目记录 | `<资料夹>/log/questions.jsonl`，只追加：拼卷时每题一行，批改或改正时再追加一行完整记录，同一题以最后一行为准 |
| 错题本 | `<课程文件夹>/practice/error-log.md` |
| 写好的卷子 | `delivery.answered_dir`，批改完挪到 `delivery.graded_dir` |
| 批改 | `delivery.feedback_dir/<日期> <CODE> 批改.pdf`，以及 `<课程文件夹>/practice/daily/<日期>/批改.md` |
| 发送记录、用量 | `<资料夹>/log/sent.jsonl`、`<资料夹>/log/usage.jsonl` |

题目记录每行的字段：`{"date","course","number","id","kind":"variant|original","retest_of":null|"<日期>/<题号>","topic","sources":[...],"marks","paper","key","status":"set|graded","score":null|"7/10","mistakes":[],"retest_due":[]}`。一道题由 `date`、`course`、`id` 认出来；它现在的状态是最后一行。

## 用户的 rules.md 模板

建档时照这个写，`<…>` 换成用户的情况，没有的节删掉。只写跟学习有关的，不写名字和其他私事。

```markdown
# 每日练习规则

默认规则见 daily-practice skill 的 references/rules.md，这里写的优先。

## 要点
（从 references/rules.md 抄第 1–9 节的要点，改成这个人的题量和课程）

## 学期日历
- 第 1 教学周从 <YYYY-MM-DD>（周一）开始。
- <课程代码> 第 <N> 周（<YYYY-MM-DD> 到 <YYYY-MM-DD>）是阅读周，不上课。
- 期末考试：<课程代码> 约在 <月份>。

## 已学范围
（有学习平台助手时可以不写。没有的话每周补一行：第 N 周，<课程代码> 讲了什么，哪天讲的。）

## 计分作业和不要碰的
- <课程代码> <作业名> 截止 <YYYY-MM-DD>：前一天和当天是轻松日；这份作业的题不拿来当原题。

## 出题偏好
- <用户说过的长期偏好，比如「图要画得跟真卷一样规整」>

## 临时安排
- <YYYY-MM-DD>：轻松日（「明天少一点」，记于 <YYYY-MM-DD>）
- <YYYY-MM-DD>：停（只批改不出卷）（「那天出门」，记于 <YYYY-MM-DD>）
```
